---
title: Setup on a read-only home opens read-only instead of doing nothing
target: web
type: fixed
---

On a home whose room layout is read-only here, such as Victoria in the Den
preview, the top-bar Setup button used to look enabled but did nothing. It now
opens the Setup rail read-only. A note says why placement is locked ("Victoria's
room layout is read-only here") and points to where the registered desk and sofa
targets are marked. The light inspector's Setup tab offers "Review fixture
placement". Where Setup can't open at all, the button reads as unavailable and a
press shows the reason. Echo is unchanged.
