---
title: Match the inline preference card to the Home chat design
target: web
type: changed
---

The inline shared-preference review card now uses Home's design language:
Geist type, spaced mono labels, square mono buttons and Home's light or dark
theme on a transparent surface. It also says plainly when the Home Agent sign-in
has expired, and a card replaced by a newer request now reads "closed · nothing
changed" instead of leaving an empty prompt.
