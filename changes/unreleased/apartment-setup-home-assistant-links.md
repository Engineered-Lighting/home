target: desktop

Setup › Home Assistant (formerly Fixture links) lists every Echo light as Linked, Shared or Not linked, lets you re-match it from the Home Assistant light list without moving any geometry, and offers Flash to blink the real light so you can check the match. Flash is the only output in the tool: it is refused while Home Assistant is offline or Travel Mode is on or unknown, and it goes through the same guarded path as every other Apartment light command. Victoria's sockets read Not linked with no picker until they are commissioned.
