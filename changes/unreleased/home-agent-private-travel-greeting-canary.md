The private desktop Agent adds an exact preview/confirm ceremony for encrypted
locality geometry and can claim one deterministic arrival greeting per visit
only after attestation, both location choices, current evidence, privacy rules,
and the active descriptor are rechecked. Direct place creation and browser,
voice, shared-display, camera, model-action, and generic greeting paths remain
unavailable.
