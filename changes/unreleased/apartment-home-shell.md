title: Apartment is the default Home workspace
target: web
type: changed
---

Home opens on the existing Apartment renderer with a shared home switcher, status, Controls and Chat workspace, and a responsive phone sheet. The previous Home remains available from the menu and `?apartmentRedesign=0`, preserving chat drafts and household saves.

Direct Apartment lighting output now verifies Travel Mode at the shared dispatch boundary and refuses stale control contexts. Virtual fixture controls, explicit off operations and the existing bounded analysis lifecycle remain separate from physical permission.
