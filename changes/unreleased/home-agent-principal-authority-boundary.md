---
title: Guard the dormant principal authority boundary
target: internal
type: security
---

Adds a negative cross-contract suite that guards the current direct integration
paths from treating the offline reviewed-person nominee as runtime authority,
keeps the public confirmation route an unconditional no-body capability
tombstone, and rejects direct/static non-test references to the legacy
self-confirming store method. It also pins the shared unverified nominee
vocabulary and the pre-authority runtime/finalizer state until the PostgreSQL
and Home Assistant ceremony prerequisites can be implemented and tested.
