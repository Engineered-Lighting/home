The Aim tab now has a Command line that shows what Home would send. Den sockets
read "Modeled · nothing sent" and Echo's engineered spotlight reads "Simulated ·
execution blocked". Expanding it shows the intent, the modeled solve and the
exact output, which for Echo is the Product Aim request with null values and its
blockers. Accepted execution and reported state read as not available, Copy
request stays disabled, and a provenance list says where each value came from.
Echo's legacy Product Aim block now lives in this ladder.

A light that Living Lights has recorded as changed by hand now shows "Changed by
hand" with its time. This is read-only: nothing hands the light back to Auto
yet.
