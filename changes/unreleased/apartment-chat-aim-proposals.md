---
title: Ask Chat to aim a light at a named aim, then Set or Discard it like a drag
target: desktop
type: added
---

In the Apartment's Chat, a message such as "aim the spot at the painting" now proposes that named aim for the light with origin "chat". The proposal shows in cyan in the room with its Set aim / Discard bar, and Chat adds a card with Set aim, Preview and Discard. The card's Set and the room bar's Set are the same Set, so they give the same simulated aim, undo history and "no hardware command sent" toast. The card then reads Aim set, Discarded or No longer proposed. Only Echo's engineered light in Simulation Mode can take a Chat aim. A physical light, or the Den while its named aims wait on the Den's store, gets its reason instead. These messages never reach lighting control, the agent or a service call.
