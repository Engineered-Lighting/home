---
title: Switch lights in either home from the Home chat
target: web
type: added
---

Home can now switch lights in Los Angeles, Victoria or both homes from the
chat: "turn off the kitchen light in Victoria" switches it and reports per
light what changed. Home asks which home or which light when a request is
unclear, and offers a status check instead of retrying when a result is
uncertain. Lighting control must be allowed once in the Home Agent panel
first, and only allowlisted lights can change.
