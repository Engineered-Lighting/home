# Claude Instructions

Follow the same repo rules as Codex and other agents.

- Read `AGENTS.md` before making code, workflow, release, deploy, or user-facing
  changes.
- Add a `changes/unreleased/*.md` fragment for meaningful user-facing or
  deploy-relevant work.
- If no fragment is appropriate, use the `no-release-note` PR label and explain
  why in the PR body.
- Do not rely on local skills or memory for release-note policy. The repo files
  are the source of truth.
