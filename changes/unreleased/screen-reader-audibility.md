---
title: The app now announces itself to screen readers
target: web
type: fixed
---

The conversation feed is a real log region (streamed replies announce once,
on completion — never per token), every toast, status chip, error block, and
voice-state change is a live status region, and the app finally has
landmarks and a heading. Every icon-only control has a name: media transport
buttons, view-angle dots, sliders (which also gained proper labels and
values), close glyphs, and the mic button — which now reports pressed state
and no longer styles a real error as "active". The slash palette exposes
full combobox semantics, apartment error toasts stay visible until
dismissed, and decorative status dots are hidden from assistive tech.
