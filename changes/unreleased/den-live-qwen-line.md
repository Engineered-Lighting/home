---
title: The live den view says what Qwen last saw
target: web
type: added
---

The den-live chip in the den's apartment view gains one line from den-live's Qwen ask, for example "Qwen: reading (close-up work) · 2 s ago". When there's no recent answer, it gives the ask's state and why, such as "Qwen: off (nobody seated)" or "Qwen: unavailable (Qwen isn't answering)". den-live asks only while Frigate sees someone in the den and den-live sees them seated, and an answer shows only when den-live was sure whose it was. The line is empty when den-live has no Qwen ask.
