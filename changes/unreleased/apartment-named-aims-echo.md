title: Save, recall and inspect named aims, starting with Echo's engineered light
target: desktop
type: added
---

In Echo Park, the engineered light now aims with the same reticle, chip and Set aim / Discard bar as the Den: a drop proposes, a spot near a saved aim snaps to it ("Snaps to “Painting”"), and an invalid spot says why with a suggestion; out of reach appears only where the light's profile configures a limit. Set aim is simulated in Simulation Mode and refused for the physical light, with no command path. A valid proposal can be saved as a named aim through the existing Apartment model save, showing Saving then Saved, Saved locally, Not saved when the model changed elsewhere (nothing is overwritten), and Replace existing / Keep both when the name already exists; an aim saved before a later scan or profile change asks to Preview it or Keep as is. Every aimable light's Aim tab lists the home's named aims as recall chips that only propose, and a named aim opens its own inspector from the room list or its marker in the room, with the lights using it, which can reach it, Aim a light here, Edit in Setup and its stable id to copy. The Den's Aim tab says its named aims wait on the Den's store.
