---
title: Every pointer-only control gains a keyboard path
target: web
type: fixed
---

Whole features were mouse-only: dismissing AI-stack log cards, switching
cameras, opening a person's profile, expanding tool details, picking a
calibration point, filtering logs, and selecting devices in the 3D
apartment. All are now reachable by keyboard — clickable text became real
buttons, table rows and graph nodes respond to Enter/Space with a visible
focus highlight, the calibration snapshot supports arrow-key point
placement, the 3D view cycles devices with n/p, the header menu implements
full arrow-key navigation, and the operations tray resizes with arrow keys.
The video labeler no longer hijacks Tab (lane cycling moved to [ and ] and
the cheat sheet says so), so its save/close/banner buttons are finally
tabbable.
