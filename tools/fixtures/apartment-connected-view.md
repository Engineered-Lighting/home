# Authored connected-view fixture

`apartment-connected-view.json` contains software fixtures only. It contains no household pixels, camera transforms, credentials or actual-room evidence.

- `scene` is the deterministic Victoria pack from `apartment-home-shell-fixtures.mjs`.
- `body` was generated by `generate-apartment-approximate-browser.py` against that pack. The actual Store/runner/ASGI path returns one supplied joint and its original bounded RAM PNG. The camera, model output and room alignment are authored. The browser must keep the single supplied joint, its approximate label and its original retirement behavior.
- `qwen` consists of twenty-two original receipts from `test_structured_camera_context.original` through the actual `StructuredCameraContext` cache. Every scene, identity and model artifact is authored. The daily perceiver scope is independent of the Lab recording.
- `camera` is a five-second moving color pattern drawn on a canvas, encoded with Chromium's MP4 MediaRecorder and split into its original initialization and three media fragments. It exercises the real MediaSource decoder and playback; it is not a camera capture.
- JEV and coordinator messages are authored in the browser test against their existing contracts. No backend inference or physical action runs.

These checks establish mounted application behavior with authored inputs. Deployment, actual apartment scans, live inference/coordinator behavior, browser clock qualification and owner movement remain separate acceptance requirements.
