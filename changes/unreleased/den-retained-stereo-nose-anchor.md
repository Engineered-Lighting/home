target: backend
type: added

Add a private adapter from existing Perception Lab detector/pose output and
retained RGB/depth originals to a separately commissioned visible-nose anchor.
It requires an existing depth-clock mapping, independent registration, temporal
error and unique-association qualifications, and durable binary and original
receipts. Missing evidence remains unavailable; this source-only work does not
qualify real anatomy, enable physical lighting, or establish live Den acceptance.
Selection rechecks current scope, Stop and the original lease after retained
binary verification completes, so verification time cannot prolong an anchor.
