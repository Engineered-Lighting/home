When den-live finds what the person holds, Home's live body figure draws it as steady points in the accent blue, beside the gold figure. The existing tag names it, such as BOOK, with the detector's confidence. Home accepts only measured and held-object points, and an object label from the detector or none. A frame without a held object looks exactly as before.
