Adds the presentation half of in-room aiming: fixture labels with hover and selected rings, a 44 px aim reticle whose chip names the surface, distance and tilt (or why it can't aim there, with Victoria's modeled-origin and uncommissioned-travel notes), a cyan proposal marker, a Set aim / Discard bar and a pending dot for the Spot tool. Nothing loads or mounts it yet, so nothing a user sees changes; it only reads pending proposals and never moves an aim, sends a command or saves anything.
