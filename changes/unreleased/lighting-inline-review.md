---
title: Confirm cross-home lighting changes in the Home chat
target: web
type: added
---

Home can now switch lights in Los Angeles, Victoria or both homes from the
chat: "turn off the kitchen light in Victoria" shows an inline review listing
exactly which lights change, and nothing happens until you confirm there.
Home asks which home or which light when a request is unclear, reports per
light whether it changed, and offers a status check instead of retrying when
a result is uncertain. Lighting control must be allowed once in the Home
Agent panel first.
