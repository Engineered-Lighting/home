---
title: Stop the Same Relationship Being Recorded Twice
target: backend
type: fixed
---

Recording that two people are partners, or that one is another's parent, could only be done once — a second identical entry was refused. The five relationships added recently had no such protection, so the same friendship could be recorded twice over and both entries would stand.

The protection existed as two separate rules, each naming one relationship. Widening the vocabulary left the new ones uncovered, and nothing said so. There is now a single rule covering every relationship, written so that adding another cannot quietly leave it out.

Two tests that had gone stale for the same reason are corrected: one still expected the old, shorter list of relationships, and another used "sibling of" as its example of something that should be rejected — which it no longer is.
