title: Authenticate dormant principal nominee provenance
target: internal
type: security
---

Adds an offline, non-deployable compiler that re-verifies the signed reviewed
identity bundle, distinct finalization envelope, and canonical private source
snapshot before resolving one exact Person-projection receipt. The receipt
choice nominates a reviewed row but proves neither operator authority nor `me`;
the result remains one `operator_review_candidate` with unverified nomination
authority, and all current-state, confirmation, binding, write, location, and
greeting claims remain false. The non-portable result must be rebuilt from the
raw artifacts.
